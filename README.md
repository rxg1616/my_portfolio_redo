# Garmin Dive Activity and Spatial Analysis Portfolio

This project analyzes personal Garmin dive activity data to examine diving patterns over time and across geographic regions. Using R, the project explores dive frequency, maximum dive depth, depth distributions, and the geographic distribution of recorded dive locations in South Florida and Belize. The workflow incorporates data cleaning, exploratory data visualization, and spatial analysis using GPS coordinates extracted from Garmin Connect.

## Data Sources

### 1. Garmin Connect Activity Data

- **Name and location of the file in this repo:** `scripts/01_processing/Activities (2).csv`
- **Title of the dataset:** Garmin Connect Activity Export
- **Source:** Garmin Connect (personal dive activity records)
- **Date of download or access:** November 2026
- **Description:** Contains raw Garmin activity records, including dive dates, activity information, maximum depth, dive duration, and other recorded dive measurements. Used as the primary dataset for data processing and exploratory analysis.

### 2. Garmin Dive GPS Locations

- **Name and location of the file in this repo:** `data/garmin_dive_locations.csv`
- **Title of the dataset:** Garmin Dive GPS Locations
- **Source:** Garmin Connect (GPS coordinates extracted from personal dive records)
- **Date of download or access:** November 2026
- **Description:** Contains GPS coordinates associated with recorded dive activities, including dive identification numbers, activity identifiers, dates, latitude, longitude, maximum depth measurements, and geographic region classifications. Includes 131 GPS-bearing activity records representing 107 distinct dive numbers. Used for spatial mapping and geographic analysis of dive locations in South Florida and Belize.

### 3. Natural Earth Geographic Data

- **Name and location of the file in this repo:** Retrieved through the `rnaturalearth` R package; not stored as a separate project data file.
- **Title of the dataset:** Natural Earth Geographic Boundaries
- **Source:** Natural Earth
- **Date of download or access:** November 2026
- **Description:** Provides geographic boundary data used to create the base map for the spatial visualization.

## Repository Structure and Contents

- `scripts/01_processing/`: Contains raw data and data-processing scripts.
  - `scripts/01_processing/Activities (2).csv`: Raw Garmin Connect activity export containing personal dive records.
  - `scripts/01_processing/data_processing.R`: Imports the raw Garmin activity data, standardizes column names using `janitor`, filters for dive-related activities, converts dates and maximum depth measurements into appropriate data types, removes duplicate records and empty rows or columns, and exports cleaned datasets as CSV and RDS files to the `clean/` directory.

- `scripts/03_content/`: Contains scripts used to generate exploratory and spatial visualizations.
  - `scripts/03_content/exploratory_data_visualization.R`: Reads `clean/cleaned_garmin_dives.rds` and produces visualizations of maximum dive depth over time, dive depth distributions, monthly dive frequency, and dive counts by depth range. Exports PNG figures to the `figures/` directory.
  - `scripts/03_content/spatial_data_visualization.R`: Reads `data/garmin_dive_locations.csv`, converts GPS coordinates into spatial features using the `sf` package, and combines dive locations with Natural Earth geographic boundaries. Uses `geom_sf()` to map individual dive locations across South Florida and Belize, with point colors representing maximum recorded dive depth in meters. Includes a north arrow, geographic coordinate labels, and a scale bar. Exports the final map as a high-resolution PNG to `results/img/`.

- `data/`: Contains spatial data used for geographic analysis.
  - `data/garmin_dive_locations.csv`: GPS coordinate dataset containing dive identification numbers, activity identifiers, dates, latitude, longitude, maximum depth measurements, and geographic region classifications. Used as the input for spatial mapping.

- `clean/`: Contains cleaned and processed Garmin activity datasets.
  - `clean/cleaned_garmin_dives.rds`: Processed Garmin dive dataset saved as an RDS file, preserving R data types for subsequent analysis.
  - `clean/cleaned_garmin_dives.csv`: Cleaned Garmin dive dataset exported as a CSV file for use in other software.

- `figures/`: Contains exploratory data visualization outputs generated by `exploratory_data_visualization.R`.
  - `figures/dive_depth_over_time.png`: Displays maximum recorded dive depth over time.
  - `figures/dive_depth_distribution.png`: Shows the distribution of maximum recorded dive depths across recorded dives.
  - `figures/dives_by_month.png`: Displays the number of recorded dives by month.
  - `figures/dives_by_depth_range.png`: Summarizes the number of dives within predefined maximum depth ranges.

- `results/img/`: Contains spatial visualization outputs.
  - `results/img/spatial_data_visualization.png`: Displays the geographic distribution of recorded dive locations across South Florida and Belize, with point colors representing maximum recorded dive depth. Includes geographic boundaries, a north arrow, and a scale bar. Produced by `scripts/03_content/spatial_data_visualization.R`.

- `my_portfolio_redo.Rproj`: RStudio project file used to open the repository from its root directory and maintain consistent relative file paths.

## Required R Packages

- `tidyverse` – Data manipulation and visualization.
- `janitor` – Data cleaning and column standardization.
- `lubridate` – Date and time manipulation.
- `sf` – Spatial data processing and geographic features.
- `ggplot2` – Data visualization.
- `ggspatial` – Map scale bars and north arrows.
- `here` – Reproducible relative file paths.
- `rnaturalearth` – Geographic base map data.

## Reproducibility

To reproduce the project:

1. Clone or download the repository.
2. Open `my_portfolio_redo.Rproj` in RStudio.
3. Install the required R packages.
4. Run `scripts/01_processing/data_processing.R` to import and clean the raw Garmin activity data.
5. Run `scripts/03_content/exploratory_data_visualization.R` to generate the exploratory visualizations.
6. Ensure `data/garmin_dive_locations.csv` is available in the project directory.
7. Run `scripts/03_content/spatial_data_visualization.R` to generate the spatial map.
8. Review the resulting datasets and visualizations in the `clean/`, `figures/`, and `results/img/` directories.

All scripts use relative file paths to support reproducibility within the RStudio project.
